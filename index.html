Deep Dive Architecture

Amazon Price Tracking System with Chrome Extension

Project Overview

An autonomous, distributed web application that solves the problem of online shopping price volatility. Shoppers frequently miss flash discounts on Amazon; this system enables them to seamlessly pin products straight from their browser and receive instant Telegram mobile alerts when prices dip below desired targets.

Key Architectural Pillars

  • Manifest V3 Chrome Extension: Injected content scripts detect Amazon ASINs and real-time DOM price elements. Users click "Track this product" in the extension popup to register tracking parameters directly with the backend.
  • Headless Scraping Daemon: Powered by Puppeteer running scheduled intervals via node-cron. Features stealth headers, simulated human scrolling, and rate-limiting to bypass bot detection.
  • RESTful API & MongoDB: Node.js & Express.js microservice maintaining historical price snapshots, tracking thresholds, and user configurations.
  • Telegram Bot Integration: When a price drop event fires, the notification dispatcher routes a formatted Telegram markdown alert with direct discount links and price delta statistics.

Ambulance Priority Traffic Control System

Project Overview

Emergency medical vehicles encounter severe delays during rush-hour urban gridlock, where minutes dictate patient survival. This system establishes an intelligent IoT & software layer that dynamically creates green traffic waves for approaching ambulances.

System Architecture & Logic

  • Emergency Telemetry Ingestion: Express.js APIs capture location, velocity vector, and patient severity tier emitted from emergency dispatch.
  • Prioritization & Corridors Algorithm: Calculates the estimated time of arrival (ETA) at consecutive intersections. Automatically modulates signal phase controllers to clear queuing traffic 45 seconds prior to arrival.
  • MongoDB Real-Time State: Records real-time intersection sensor states, current signal phases, emergency logs, and automated fail-safe overrides.
  • React Operations Center: Interactive control dashboard allowing municipal traffic operators to monitor emergency corridors, override manual overrides, and review clearance analytics.
